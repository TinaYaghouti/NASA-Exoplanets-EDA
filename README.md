## Project Overview
This project performs a comprehensive Exploratory Data Analysis (EDA) on the NASA Exoplanets dataset. The main goal is to analyze the physical and orbital characteristics of exoplanets to identify key factors that determine whether a planet resides in the "Habitable Zone".

## Primary Questions
1. **Univariate Analysis:** What is the distribution of exoplanet sizes, masses, and discovery methods?
2. **Bivariate Analysis:** How does the distance from the host star relate to the planet's temperature?
3. **Multivariate Analysis:** What combination of features makes a planet a candidate for habitability?

## Analysis Steps
- **Data Preparation & Missing Values:** Verifying data quality.
- **Univariate Analysis:** Exploring the distribution of planet radius and temperature.
- **Outlier Detection:** Using boxplots to identify extreme planetary values.
- **Bivariate Analysis:** Visualizing relationships (Orbital Period vs. Temperature, Radius vs. Mass).
- **Multivariate Analysis:** Creating a custom `in_habitable_zone` feature and comparing planets.
- **Trend Analysis:** Investigating how telescope technology has evolved over time.
